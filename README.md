# AXEL · LuCI theme family

Три самостоятельных визуальных направления для OpenWrt: **AXEL Mesh**, **ATLAS**, **MRx**.

**Статус: development 0.2.** Помимо макетов добавлены исходники настоящих LuCI-пакетов AXEL Mesh и ATLAS, общая оболочка, тесты и SDK-сборка. Аппаратная совместимость пока не подтверждена; готовым релизом это не объявляется. Макеты содержат демонстрационные данные, установочная тема — нет.

## Направления

| Вариант | Характер | Структура |
| --- | --- | --- |
| AXEL Mesh | Тёмный сине-графитовый, бирюзовый акцент, мягкие панели | Боковая навигация, обзор сети |
| ATLAS | Согласованное наследие проекта: чёрная шапка, белый/тёмный фон, синий акцент, оригинальные логотип и аватар | Верхняя навигация, бегущая строка, меню профиля |
| MRx | Визуальное направление ещё не согласовано | Пакет не создаётся до согласования |

ATLAS Heritage одобрен как направление; AXEL Mesh остаётся в доработке. Первые зелёный ATLAS и коралловый MRx из `preview/index.html` — архив предложений, а не актуальный дизайн. Слово Mesh — название оформления, оно не включает mesh-сеть и не меняет сетевые настройки.

## Посмотреть макеты

Актуальный согласованный макет ATLAS: `preview/atlas-heritage.html`. Он включает Light/Dark, адаптивность, верхнюю бегущую строку и меню с оригинальной заглушкой аватара. `preview/index.html` сохранён как архив ранних предложений.

Все показатели и устройства в макете — демонстрационные. Ввод паролей отключён, обращения к роутеру отсутствуют. Макет не является альтернативной панелью администрирования.

## Пакеты и сборка

`packages/luci-theme-axel-core` содержит общую оболочку, адаптивные стили и переключение Light/Dark. Две темы добавляются в штатный список LuCI и **не выбираются автоматически**. При удалении выбранной темы обработчик возвращает Bootstrap. Bootstrap остаётся зависимостью: его базовые формы и меню не копируются и не удаляются.

Скрипт `scripts/build-sdk.sh` рассчитан на одноразовую Linux x86_64 среду. Он проверяет SHA-256 официального SDK OpenWrt 25.12.5 mediatek/filogic и сохраняет три development APK и SHA256SUMS. Workflow запускает те же проверки. Архив SDK, npm-код, макеты и приватный VPN-модуль в пакеты темы не включаются.

Проверки: `node scripts/check-packages.mjs`, `node scripts/check-atlas-preview.mjs`. Подробности установки и отката — [docs/install.md](docs/install.md). На единственный рабочий роутер устанавливать только после проверки сборки и при наличии проводного/SSH-доступа.

Сборка `0.2.0-r3` успешно прошла официальный SDK 25.12.5; APK распакованы и проверены без установки, все шесть ucode-шаблонов скомпилированы нативным компилятором. SHA-256 скачанных пакетов проверены. Это ещё не аппаратное испытание: [отчёт и оставшиеся проверки](docs/verification-0.2.md).
