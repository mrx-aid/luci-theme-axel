# AXEL · LuCI theme family

Три самостоятельных визуальных направления для OpenWrt: **AXEL Mesh**, **ATLAS**, **MRx**.

**Статус: дизайн-прототип, не готовый пакет для роутера.** Устанавливаемых APK и релизов пока нет. Макеты показывают предполагаемый внешний вид, а не состояние конкретной сети.

## Направления

| Вариант | Характер | Структура |
| --- | --- | --- |
| AXEL Mesh | Тёмный сине-графитовый, бирюзовый акцент, мягкие панели | Боковая навигация, обзор сети |
| ATLAS | Светлый минеральный, глубокий зелёный акцент | Верхняя навигация, более широкие информационные блоки |
| MRx | Компактный графитовый, кораллово-красный акцент | Узкая боковая панель, плотная компоновка |

Названия согласованы; цвета и композиция — первое предложение, ещё не утверждённый финальный дизайн. Слово Mesh — название оформления, оно не включает mesh-сеть и не меняет сетевые настройки.

## Посмотреть макеты

Скачайте репозиторий и откройте `preview/index.html` в браузере. Внизу есть переключатель трёх вариантов. Можно открыть разделы «Обзор», «Wi-Fi», «Система» и «Экран входа».

Все показатели и устройства в макете — демонстрационные. Ввод паролей отключён, обращения к роутеру отсутствуют. Макет не является альтернативной панелью администрирования.

## План реализации

- [x] Первые интерактивные макеты трёх направлений.
- [ ] Утверждение визуального направления и мобильной версии.
- [ ] Общая основа темы с отдельными пакетами `luci-theme-axel`, `luci-theme-atlas`, `luci-theme-mrx`.
- [ ] Интеграция штатных шаблонов и форм LuCI; сохранение предупреждений и подтверждений.
- [ ] Проверка на OpenWrt 25.12 / APK: вход, формы, вкладки, диалоги, переключение темы, мобильный экран.
- [ ] Воспроизводимая сборка, контрольные суммы, инструкция установки и возврата к Bootstrap.

Будущие пакеты должны устанавливаться рядом со штатной темой, а не заменять её файлы. Ни установка, ни переключение темы не должны менять Wi-Fi, WAN, firewall, VPN или учётные данные.
