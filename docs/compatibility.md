# Совместимость и границы изменений

Целевая начальная ветка: OpenWrt 25.12 с современным LuCI и APK. Поддержка старых веток и IPK не заявлена до отдельной проверки.

## Принципы

- Тема — представление стандартного LuCI, не новый сервер управления.
- Использовать штатную авторизацию, проверку прав и механизм применения UCI.
- Не подменять предупреждения, сообщения об ошибках, состояния ожидания или подтверждения применения настроек.
- Не выдавать демонстрационные данные за реальные: в пакетах все значения должны поступать из штатных источников LuCI.
- Не загружать шрифты, аналитику, картинки или скрипты с внешних сайтов из интерфейса роутера. Прототип не задаёт финальный набор зависимостей.
- Не удалять Bootstrap; переключение должно выполняться через «Система → Система → Язык и стиль».
- Не включать автоматически сетевые функции, включая Mesh.
- Не применять собственную тему автоматически при установке до явного выбора пользователя.

## Проверки перед релизом

1. Чистая установка, обновление, удаление, возврат к Bootstrap.
2. Вход/выход, неправильный пароль, истечение сессии.
3. Таблицы, вкладки, поля, диалоги, длинные имена и русский/английский языки.
4. Клавиатура, видимый фокус, контраст, 320/375/768/1024/1920 px.
5. Загрузка/скачивание пакетов через штатный интерфейс.
6. Сохранение/применение с подтверждением и аварийным возвратом LuCI.
7. Отсутствие изменений network, wireless, firewall, VPN и паролей при установке темы.
8. Работа без доступа в интернет; отсутствие внешних запросов из темы.

Статус прототипа не означает, что эти проверки уже пройдены установленной темой.
