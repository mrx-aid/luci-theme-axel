# Development-пакеты: установка и откат

Цель: OpenWrt 25.12.5 / современный LuCI / APK. Статус: разработка, не проверенный аппаратный релиз.

1. Убедиться, что workflow завершился успешно, получить APK и SHA256SUMS именно из нужного запуска. Проверить суммы. Артефакт не является обещанием совместимости с произвольной прошивкой.
2. Сохранить настройки роутера. Не удалять luci-theme-bootstrap, Argon и Proton2025. Подключиться к LAN кабелем; сохранить SSH-сессию для отката.
3. Установить `luci-theme-axel-core`, затем `luci-theme-atlas` и/или `luci-theme-axel`. Они требуют Bootstrap; если его нет, сначала установить штатный пакет из репозитория прошивки.
4. Development APK могут не иметь доверенной роутеру подписи. Разовое разрешение непроверенной подписи допустимо только для проверенного собственного артефакта; глобальную проверку подписей отключать не нужно.
5. В «Система → Система → Язык и стиль» выбрать ATLAS либо AXEL Mesh. Установка сама тему не меняет.
6. Проверить вход, меню, формы, модальные окна, сохранение/применение с откатом, Light/Dark, узкий экран. Тема хранит только визуальный режим в localStorage; ключи VPN туда не записываются.

Если страница не отображается, в SSH вернуть штатное оформление:

```sh
uci set luci.main.mediaurlbase='/luci-static/bootstrap'
uci commit luci
```

Затем открыть LuCI заново с обновлением кэша. Не сбрасывать роутер и не менять network/firewall ради исправления темы.

Удаление выбранной темы также переключает mediaurlbase на Bootstrap. Общий core удалять только после зависимых тем. Пакеты не меняют WAN, LAN, Wi-Fi, firewall, DNS, VPN или пароль администратора.

MRx отсутствует в установочных пакетах намеренно: его оформление ещё не согласовано.
